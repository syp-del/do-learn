# Do-Learn Do-Learn

초등학교 1학년 쌍둥이 자매를 위한 읽기·낱말·할 일 앱.

- **앱**: 단일 HTML 파일 `index.html` (빌드 도구 없음)
- **배포**: Vercel 정적 호스팅 + 서버리스 함수 두 개
- **데이터**: Supabase (Postgres + Storage)

---

## 구조

```
index.html      앱 전체 (HTML/CSS/JS 한 파일)
api/_ai.js      AI 공통 코드 (Gemini/Claude 고르기·부르기·오류 풀이) — 주소로 열리지 않는다
api/dict.js     사전 — 영어(한국어 뜻 + 쉬운 영어 풀이)·한글 (GET 이면 연결 확인 페이지)
api/coach.js    🦜 뚜뚜 — 원고 준비 · 녹음 피드백 · 자연스러운 목소리 (가족 ID 확인 후에만)
api/book.js     책 찾기 — 알라딘 → 카카오 순으로 서버에서 조회
vercel.json     coach 함수 최대 실행 시간(60초)
CLAUDE.md       Claude 작업 안내 — "아이들이 즐겁게" 원칙, 성향 맞춤, 코드 규칙
package.json    type: module (Vercel 함수가 ESM), 의존성은 @anthropic-ai/sdk 하나
```

앱은 열린 환경을 스스로 알아본다.

| 어디서 열렸나 | 저장 | 사전 | 책 찾기 |
|---|---|---|---|
| Vercel(일반 웹) | Supabase | `/api/dict` | `/api/book` |
| claude.ai Artifact | Artifact `db` | Claude `sample` | 브라우저에서 카카오 직접 |
| 그 외(파일 열기 등) | 메모리(경고 배너) | 불가 | 수동 입력 |

## 배포하기

### 1. Vercel에 연결
1. https://vercel.com/new 접속
2. `syp-del/do-learn` 저장소를 **Import**
3. Framework Preset은 **Other**, 빌드 설정은 건드리지 않는다 (빌드 과정이 없다)
4. **Deploy**

이후 `main`에 푸시할 때마다 자동 배포된다.

|---|---|---|

### 3. Supabase
프로젝트 `do-learn` (서울 리전)에 이미 스키마가 들어가 있다.
`index.html` 상단의 `SB_URL`, `SB_KEY`가 그 프로젝트를 가리킨다.

여행·그림일기 사진을 가족 모든 기기에서 보려면 비공개 버킷 `memories`가 필요하다(아래 ‘데이터가 보호되는 방식’).
지금 프로젝트에는 이미 만들어 두었다. 새 프로젝트라면 `supabase/memories.sql`을 SQL Editor에서 한 번 실행한다(여러 번 실행해도 된다).
버킷이 없으면 사진은 찍은 기기(IndexedDB `dolearn-photos`)에만 저장되고, 나머지 기록은 그대로 동기화된다.

## 데이터가 보호되는 방식

가족마다 UUID 하나(`familyId`)를 갖는다. 주소 끝에 `#f=<UUID>` 로 붙고, 이 기기에도 저장된다.

- 앱은 모든 요청에 `x-family-id` 헤더를 실어 보낸다.
- Postgres RLS가 그 헤더와 `family_id`가 일치하는 행만 돌려준다.
- 공개 키(`SB_KEY`)만 알고 헤더가 없으면 **읽기는 빈 결과, 쓰기는 401**이다.

즉 **주소를 아는 사람만** 기록을 본다. 다른 기기에서 이어 쓰려면
부모님 화면 → 설정 → `우리 가족 주소`를 복사해 그 주소로 열면 된다.
아무에게나 알려주면 안 되는 주소다.

표지 사진은 `covers` 버킷에 `<familyId>/<랜덤>.jpg` 경로로 올라간다.
버킷은 공개라 표지 주소로는 누구나 볼 수 있지만, 목록 보기·올리기·지우기는
`x-family-id` 헤더의 가족 폴더 안에서만 된다(storage 정책 `covers_read_own` / `covers_write_own` / `covers_delete_own`).
그래서 버킷 목록으로 다른 가족의 폴더 이름(가족 ID)을 알아낼 수 없다.

여행·그림일기 사진은 **비공개** 버킷 `memories`에 `<SHA-256(familyId)>/<종류>-<랜덤>.jpg`로 올라간다.
- 폴더 이름이 가족 ID가 아니라 그 해시라서, 사진 주소가 새어도 가족 기록 전체가 열리지 않는다.
- 사진은 하루짜리 서명 주소(signed URL)로만 보인다. 정책 `memories_read_own` / `memories_write_own` / `memories_delete_own`이 헤더의 가족 해시 폴더만 허락한다.
- 올리기 전에 긴 쪽 1600px로 다시 그려서, 사진 속 위치 정보(EXIF)가 사라진다.
- 앱은 `memories_ready()`(버킷이 있으면 true)로 버킷이 있는지 확인한다.

### 테이블

| 테이블 | 내용 |
|---|---|
| `items` | 앱의 모든 기록. `coll`(books/words/todos/sessions/unlocks/requests/profiles/dict/scripts/speech/kudos/dlists/dprog/spell/think/goals/trips/wishes/stamps) + `data` jsonb |
| `settings` | 가족별 설정 한 줄 (PIN, 놀이 시간, 카테고리, 날씨 등) |

기록을 jsonb 한 칸에 담아 앱이 쓰는 객체 모양을 그대로 저장한다.
필드를 늘려도 마이그레이션이 필요 없다.

동기화는 실시간 구독 대신 **5초 폴링**이다(화면이 보일 때만). 승인 알림에는 충분하고,
RLS 헤더 방식과 충돌하지 않는다.

## 사전 연결 (Gemini / Claude)

단어 탭의 사전은 `api/dict.js`가 AI에게 낱말 뜻을 물어 온다.
`GEMINI_API_KEY`가 있으면 Gemini(`gemini-3.5-flash-lite`, 무료 등급 — 찾은 낱말이 구글 서비스 개선에 쓰일 수 있다),
없고 Claude 키가 있으면 Claude(Haiku 4.5)를 쓴다.
설정은 **https://<배포 주소>/api/dict** 페이지가 단계별로 안내하고,
키가 보이는지와 실제로 찾아지는지(`?test=1`)를 확인해 준다.

1. https://aistudio.google.com/apikey → Create API key (`AIza`로 시작, 결제 정보 필요 없음)
2. 버셀 환경변수 `GEMINI_API_KEY`에 붙여넣기 → Redeploy
3. 확인 페이지에서 **시험해 보기**

키가 틀리면 "사전 열쇠가 맞지 않아요", 무료 사용량을 넘으면 "사전이 조금 바빠요",
(Claude) 크레딧이 없으면 "사전 이용권이 다 됐어요"가 아이 화면에 뜬다.

## 텔레그램 승인 알림

아이가 `🔔 부모님께 승인 받기`를 누르면 `api/notify.js`가 부모님 텔레그램으로 메시지를 보낸다.
메시지의 버튼을 누르면 앱이 열리고, PIN을 입력해 승인한다.

설정은 **https://<배포 주소>/api/telegram-setup** 페이지가 단계별로 안내한다.
토큰이 맞는지, chat id가 무엇인지 보여주고, 테스트 메시지를 보낼 수 있다.

1. 텔레그램 **@BotFather** → `/newbot` → 이름 → 아이디(`_bot`으로 끝남) → 토큰 받기
2. 버셀 환경변수 `TELEGRAM_BOT_TOKEN` 추가 → Redeploy
3. 텔레그램에서 만든 봇에게 **시작(Start)** 또는 아무 메시지
4. 설정 페이지에서 chat id 복사 → `TELEGRAM_CHAT_ID` 추가 → Redeploy
5. 설정 페이지에서 **테스트 메시지 보내기**

봇 토큰은 서버 환경변수에만 둔다. 앱 코드나 저장소에 넣지 않는다.

## 🦜 뚜뚜 스피치 교실

영어 스피치 대회를 준비하는 앵무새 선생님 뚜뚜와 한 문장씩 수업한다.

1. **뜻 알기**: 영어 문장 + 한국어 뜻 + 그림 힌트 + 발음 팁
2. **듣기**: 뚜뚜가 읽어 준다(🐢 천천히 / 🐰 보통 / 🚀 대회 속도). 읽는 단어에 불이 켜진다.
3. **"자 이제 말해볼까?"**: 녹음한다. 말이 끝나면 저절로 멈춘다.
4. **피드백**: 별 1~3개, 칭찬, "이렇게 말해보면 더 좋아요", 다시 들어볼 단어, 목소리 크기·빠르기·끝 높낮이, 내 목소리 파도(음높이 그래프)
5. **외우기**: 보고 말하기 → 몇 개 가리기 → 첫 글자만 → 뜻만 → 외웠다! 이후 1·2·4·7·14일 뒤에 복습한다. 이어 말하기(눈덩이)도 있다.
6. **처음부터 끝까지 이어 말하기**: ECC speech 연습을 마친 뒤 해 볼 수 있다. 시간 제한·그림 힌트 없이 끝까지. 첫 녹음은 계속 보관한다.

**부모님 화면 → 🦜 스피치**
- 원고를 붙여넣으면 문장으로 나눈다. 한국어 해석 줄이 섞여 있으면 짝지어 준다.
- 뚜뚜(AI)가 한국어 뜻·그림 힌트·힘줄 단어·끝 억양·발음 팁을 채운다. 부모님이 고칠 수 있다.
- 대회 날짜는 선택이다. 하루 연습량을 정하는 데만 쓴다.
- 원고를 저장하면 아이에게 '🦜 뚜뚜랑 스피치 연습' 할 일이 생기고, 오늘 미션을 마치면 저절로 체크된다.

**개인정보**
- 아이 녹음은 **기기(IndexedDB)에만** 저장한다.
- **AI 듣기는 기본 꺼짐**이다. 부모님이 안내를 읽고 켜면 한 문장 녹음(몇 초)만 Gemini로 보낸다.
  - 이름이 든 문장은 보내지 않는다.
  - 무료 등급은 보낸 내용이 구글 서비스 개선에 쓰일 수 있다.
  - Gemini API 약관은 18세 미만이 쓰는 서비스에 쓰지 않도록 정하고 있다. 사전 기능도 마찬가지다.
- AI 듣기가 꺼져 있어도 기기 안에서 소리 크기·빠르기·쉬는 곳·끝 높낮이를 봐준다.
- **자연스러운 목소리**(Gemini 음성 합성)는 뚜뚜가 할 말만 보낸다. 한 번 만든 목소리는 기기에 저장해 다시 쓰고, 안 되면 기기 목소리로 바로 넘어간다.

**아이별 맞춤**: 부모님 화면 → 아이 → 성향(승부욕·공부 스타일·강점)을 고르면 뚜뚜의 말과 퀴즈 방식이 아이에게 맞춰진다.

## 🎤 ECC speech 연습

스피치 탭 → `🎤 ECC speech 연습`. 원고를 한 문장씩 읽는 연습이다(그림 힌트·시간 제한 없음).

1. 🔊 뚜뚜 목소리로 먼저 들어 본다(🐢 천천히 · 🐰 보통 · 🚀 원래 속도).
2. 🎤를 누르면 3·2·1 뒤에 “말해요!” — 그때 소리 내어 읽는다(앞부분이 잘리지 않게 마이크를 먼저 켜 둔다). 기기 음성 인식이 되는 곳에서는 맞게 읽은 단어가 **바로 초록색**으로 바뀐다.
3. 다 읽으면 🟢 잘 읽은 단어 · 🔴 한 번 더 연습할 단어. 빨간 단어를 누르면 “여기 이렇게 말해 보자!” 하며 천천히 들려주고 발음 팁을 준다.
4. 🔁 다시 해보기는 언제든(녹음 중에는 “처음부터 다시”). 문장마다 결과 색과 별이 남아서 다음에 열어도 보인다.
5. 끝나면 원고 전체가 초록·빨강으로 보이고, 별이 적은 문장만 다시 하거나 처음부터 끝까지 이어 말해 볼 수 있다.

- 발음·유창성·억양까지 자세히 보려면 부모님 화면 → 🦜 스피치 → **AI 듣기**를 켠다(기본은 꺼짐). 꺼져 있으면 기기 음성 인식 + 소리 크기·빠르기·쉼·끝 높낮이로 본다.
- 원고에 `{name}`이라고 쓰면 아이마다 영어 이름(부모님 화면 → 아이 → 🔤 영어 이름)이 들어간다. 이름이 든 문장은 밖(AI)으로 보내지 않는다.

## 📒 배움기록과 반짝 왕관

- **실력 왕관**(책왕·단어왕·성실왕·연습왕·받아쓰기왕): 앞선 아이가 받는다. 한 아이가 절반보다 많이 앞서면, 넘치는 왕관은 '둘이 함께' 왕관이 된다.
- **개인 왕관**(💪 노력왕·😇 착한왕·💭 생각왕·🌏 탐험왕·🌱 성장왕): 형제끼리 겨루지 않는다. 기준을 넘으면 둘 다 받는다.
- **함께 모으기**: 둘이 합쳐 책·받아쓰기·생각 기록을 모은다.
- **💌 칭찬 스티커**: 아이끼리 하루 3번까지 보낸다. 부모님도 아이 화면에서 줄 수 있다.
- **💬 대화방**: 오른쪽 위 💬를 누르면 오른쪽에서 열린다. 👪 우리 가족방은 늘 있고, ➕ 새 방 만들기로 초대할 사람을 골라 단체방을 여러 개 만든다. 글과 🎁 칭찬 스티커를 주고받는다(아이끼리 칭찬 스티커는 하루 3번까지). 엄마 아빠로 쓰려면 부모님 비밀번호. 🔒 방에 초대받지 않은 사람은 누구든(엄마 아빠도) 그 방에 들어가거나 글을 볼 수 없다. 안 읽은 글은 방마다, 💬에는 모두 더한 빨간 숫자.
- **🎤 음성 메시지**: 대화방에서 🎤을 누르고 말한 뒤 ⏹ 보내기(30초까지). ▶를 누르면 들린다. 소리는 우리 가족 데이터에만 두고 2주가 지나면 지워진다.
- **👪 부모님 모드**: 부모님 관리 → 비밀번호 → 담당 아이를 고르면(처음 한 번, 기억한다) 그 아이와 똑같은 화면이 나오고, 아래 탭 맨 끝의 **👪 부모님 관리** 탭에 할 일·스피치·받아쓰기·생각·아이·부모님·알림·놀이 승인·설정·기록 관리가 모두 있다. 머리줄의 이름을 누르면 다른 아이로 바꾸고, 🏠나 🔒 나가기를 누르면 끝(15분 동안 아무것도 안 해도 잠긴다).
- **🧹 새로 시작하기**: 부모님 관리 → 설정 맨 아래(대표 관리자만). 스피치 원고·급수표·아이 프로필(이름·영어 이름·그림 비밀번호…)·부모님 계정·설정은 남기고, 아이별 기록과 샘플 데이터를 모두 지운다. ‘지우기’라고 적어야 된다. 먼저 💾 전체 기록 내보내기로 저장해 두자.
- **➕ 사용자 추가**: 시작 화면의 “사용자 추가” 칸 → 🧒 아이(부모님 비밀번호) 또는 👪 부모님(대표 관리자 비밀번호로 새 닉네임·비밀번호).
- **👪 부모님 계정**: 처음 정한 비밀번호로 부모님 관리에 들어오면 “👪 누구세요?” — 닉네임을 고르거나, ➕ 새 닉네임을 만들고 따로 비밀번호를 정한다(다음부터는 그 비밀번호로 바로 들어온다). 한 번 들어오면 15분 동안(아무것도 안 하면) 대화방에서는 비밀번호를 다시 묻지 않고 그 닉네임으로 말한다. 🔒 나가기를 누르거나 아이가 자기 공간에 들어가면 끝. 부모님 화면 → 👪 부모님. 대표 관리자(기본 닉네임 “뚜뚜아빠”)가 부모님을 닉네임·그림·비밀번호로 추가한다. 비밀번호를 누르면 누구인지 알아보고, 대화방에서는 저마다 닉네임으로 말한다. 텔레그램 알림 연결과 텔레그램 단추로 연 승인은 대표 관리자만 한다.
- **🔐 그림 비밀번호**: 시작 화면에서 아이를 고르면 그림 4개를 순서대로 누른다. 처음에 아이가 직접 정하고, 잊으면 부모님 비밀번호로 연다(부모님 화면 → 아이에서 지우면 다시 정한다). 배움기록과 대화방은 함께 본다.
- **💌 오른쪽 알림 카드**: 부모님이 쪽지를 붙이거나 칭찬 스티커가 오면, 받는 아이 화면 오른쪽에 카드가 살짝 떠오른다. 🔊로 읽어 주고, “고마워요 💕”를 누르면 들어간다(다른 기기에서도 다시 안 뜬다).

## ✏️ 받아쓰기

- 부모님 화면 → ✏️ 받아쓰기에서 급수표를 넣는다. 한 줄에 한 문장이고, 번호(1. 2) ③)는 저절로 빠진다. 시험 날과 누가 연습할지도 정한다.
- 📷 급수표 사진을 찍으면 AI가 글자를 읽어 칸에 채운다. 사진에 급수가 여러 개면 한꺼번에 넣을 수 있다. 부모님이 꼭 확인한다.
- 뚜뚜가 한 문장을 천천히 두 번 읽어 준다.
  - **📝 공책에 쓰기**: 다 쓰고 나서 정답을 보며 스스로 ⭕❌를 누른다.
  - **⌨️ 패드에 쓰기**: 자동으로 채점한다. 받침·모음·첫소리·띄어쓰기(∨ 띄어 써요, ⁀ 붙여 써요)·문장 부호를 나눠서 알려 주고, ‘가치’처럼 소리 나는 대로 쓴 것도 알아챈다.
  - 틀린 문장은 **🔁 오답 노트**에 모였다가, 다시 맞히면 빠진다.
- 아이별 맞춤: 척척 빠른 아이는 “한 번만 더 읽어 볼까?”로 확인하는 습관을, 꼼꼼한 아이는 🎯 한 번만 듣고 쓰기 도전을 받는다.
- **🔤 영어 철자 놀이**: 단어 가방과 스피치 원고의 단어로 🧩 글자 맞추기 · 🎧 듣고 쓰기 · ✏️ 빈칸 채우기. 맞히면 1·2·4·7·14·30일 뒤에 다시 나온다.

## 💭 생각 키우기

- **🌟 오늘의 질문**: 친구·공평·용기·자연·상상·가족·마음·나·세상·환경 질문 60개 중 하루 하나. 답하면 뚜뚜가 한 번 되묻는다. 둘 다 답해야 서로의 생각이 보인다. 부모님 화면 → 💭 생각에 **저녁 대화 카드**가 뜬다.
- **🌈 하루 돌아보기**: 기분 스티커 + 잘한 것 · 어려웠던 것 · 내일은? 속상한 날이면 부모님 화면에 알려 준다.
- **🤝 이번 주 나의 약속**: 부모님이 준비한 메뉴에서 아이가 1~3개를 고른다. 책·받아쓰기 같은 건 저절로 세고, 금요일부터 스스로 돌아본다.
- **🔎 궁금해 노트**: 궁금한 것 → 내 생각 먼저 → 책·엄마 아빠·해 보기로 알아보기 → 알게 된 것을 내 말로.
- **🧩 문제 해결 미션**: 문제 알기 → 아이디어 3개 → 하나 고르기 → 해 보기 → 돌아보기. 부모님이 미션을 더 넣을 수 있다.
- **🎨 그림일기**: 손가락으로 그리고 글을 쓴다. 🔍 맞춤법 살펴보기는 고칠 낱말과 힌트만 알려 주고, 고치는 건 아이가 한다.
- **⏱ 예상 시간**: 할 일을 시작할 때 몇 분 걸릴지 고르고, 끝나면 진짜 시간과 비교한다.
- **📖 책 한 줄 느낌**: 다 읽은 책에만 묻는다. 느낌 낱말(재미있었어요·신기했어요…)을 누르거나 🎙 말로 써도 된다.
- **🤖 AI 도우미**(궁금해 노트 설명·일기 맞춤법): 부모님 화면 → 💭 생각에서 켤 때만 동작한다. 기본은 꺼짐이고, 이름은 가려서 보낸다.

## 🌏 세계

- **지구본**: 손가락으로 돌리고, 나라를 누르면 나라 카드(국기·수도·지금 몇 시·인사말)가 뜬다. 가 본 곳은 아이 색으로 칠해진다.
- **⭐ 오늘의 나라**: 42개 나라를 돌아가며 보여 준다. 그 나라 말 인사(🔊), 랜드마크, 음식, 재미있는 사실이 나온다.
  - 📖 알아봤어요, 🔎 집 지구본에서 찾았어요(부모님이 비밀번호로 확인)를 누르면 여권에 도장이 찍힌다.
- **✈️ 여행 기록**: 어디·언제·누구랑·한 일·먹은 것·제일 기억에 남는 것·사진(6장까지). 제주도·오사카·괌·다낭 같은 곳은 핀 위치가 저절로 들어간다.
- **🛂 나의 여권**: 여행한 나라와 찾은 나라의 도장을 모아 보여 준다.
- **⭐ 가고 싶은 곳**: 이유와 여행 계획(하고 싶은 것·누구랑·언제·챙길 것)을 적는다.

## 🧠 생각 놀이

놀이 탭에 있는 문제 해결 놀이 4가지다. 문제를 그때그때 만들어 내므로 매번 새 문제가 나온다.
3번 연속으로 맞히면 한 단계 어려워지고, 레벨은 아이별로 저장된다.

| 놀이 | 하는 일 | 키우는 힘 |
|---|---|---|
| 🧱 쌓기나무 탐험대 | 숨은 나무까지 개수 세기, 위·앞·옆에서 본 모양, 몇 개 더 쌓으면 상자 모양이 될까, 위에서 본 모양에 층수 쓰기 | 공간 감각 |
| 🍕 피자 가게 | 같은 양 찾기(1/2 = 3/6), 남은 피자 똑같이 나누기, 두 손님 주문 합치기(1/2 + 1/3), 남은 것에서 전체의 1/4 주기 | 분수 감각 |
| ✏️ 한붓그리기 | 모든 칸을 한 번씩 지나기. 4×4에서 8×8까지 커지고, 3단계부터 🏁 칸에서 끝나야 한다 | 계획·끈기 |
| 🔍 패턴 탐정 | 두 가지가 다른 주기로 바뀌는 규칙, 갔다 돌아오는 규칙 등을 찾아 빈칸 채우기. ?가 가운데에도 숨는다 | 규칙 찾기 |

틀리면 "괜찮아요!"와 함께 정답과 그 까닭을 보여 준다(피자 가게는 먼저 힌트).

## 🌱 이또 — 풀숲 친구 찾기

1. **정원**: 손가락으로 좌우로 쓱쓱 문지르면 풀이 깎이고, 숨어 있던 친구가 뿅! 나타난다.
2. 나타난 친구를 누르면 **땅속 탐험차**(5자리 — 찾은 친구를 모두 태울 수 있다)에 쏙 탄다.
3. **🚗 출발!** → 하늘로 슝~ 날아올랐다가 빙글 돌아 땅속으로 쏙! **🐜 개미집**에 도착한다.
   - 개미집은 큰 방(놀이방·낮잠방·간식방·노래방·보물방)이 굴로 이어져 있고, 방마다 버블이 3~4개 있다. 방이 차면 아래로 더 판다.
   - 차에 탄 친구를 누르고 빈 버블을 눌러 옮겨 담는다.
   - 친구들은 굴을 따라 다른 방에 놀러 갔다 오기도 하고 이사도 한다. 버블 속 친구를 누르고 빈 버블을 누르면 그리로 걸어가고, 친구 둘을 차례로 누르면 같이 논다.
4. **🌱 정원으로** → 땅 위로 뿅! 풀이 새로 자라 있다.

친구는 8종이고 반짝이·달님이는 아주 드물게 나온다. 📖 친구 도감과 개미집의 버블 자리는 아이마다 저장된다.

가끔 한 번씩 특별한 손님도 온다.
- 🌈 **특별한 친구**(알록이·포롱이·나풀이): 풀숲 어딘가가 ✨ 반짝반짝 빛나면 거기에 숨어 있다. 만날 때마다 ⭐.
- 🐢 **큰 친구**(통통이·느긋이): 쿵… 쿵… 발소리가 들리면 나온다. 몸이 커서 풀을 더 많이 깎아야 나오고, 차에서는 **두 자리**에 앉는다.
- 한동안 못 만나면 조금씩 잘 나온다. 찾았는데 자리가 없어서 못 태운 친구는 다음 정원에서 기다린다.
- 🤝 같이 찾기에서도 나온다.
친구들은 이 앱에서 새로 그린 캐릭터다. 다른 회사의 캐릭터(포켓몬스터 등)는 저작권 때문에 쓰지 않는다.

## 🤝 같이 놀기

놀이 탭 → `🤝 같이 놀기`. 가족이 **각자 자기 기기**에서 들어와 2~4명이 같은 놀이를 함께 한다. 엄마 아빠도 들어올 수 있다.

- **현황판**: 사람마다 🔓 놀이 허락(부모님 승인, 남은 시간) · ✅ 들어왔어요 · 👍 준비됐어요. 허락 전이면 그 자리에서 🔔 부모님께 허락을 받는다.
- 누가 방에 들어오면 다른 아이 화면에 “🤝 ○○가 같이 놀자고 기다려요!” 카드가 뜬다.
- 놀이 목록의 **🤝 같이** 단추, 이또 정원, 숨바꼭질 시작 화면에서도 그 놀이를 골라 둔 채로 바로 부를 수 있다.
- 엄마 아빠는 부모님 화면 → 놀이 승인 → **🤝 아이들과 같이 놀기**로 들어온다(놀이 허락은 필요 없다).
- 들어온 사람이 모두 👍 준비되면 3·2·1 같이 시작한다.
  - 🔍 **틀린 그림 찾기**(대결): 모든 기기에 똑같은 그림(정원·놀이방·바닷속). 다른 곳 5개를 먼저 다 찾으면 1등(90초).
  - 🌱 **풀숲 친구 찾기**(함께): 같은 풀숲을 다 같이 깎는다. 한 사람이 깎으면 다른 기기에서도 똑같이 깎이고, 숨은 친구 6마리를 힘을 합쳐 찾는다. 찾은 친구는 각자 이또 도감에 들어간다.
  - 🧸 **숨바꼭질 힘을 합쳐**(함께): 다 같이 찾은 곰돌이를 모아 60초 안에 목표(한 사람당 15마리)를 채운다. 🐰 토끼는 -1.
  - 🧸 **숨바꼭질 대결**: 똑같은 순서로 곰돌이가 튀어나온다. 60초 동안 점수가 높은 사람이 1등.
- 별: 대결은 1등 ⭐2 · 나머지 ⭐1, 함께 놀이는 해내면 모두 ⭐2 · 아니어도 ⭐1 — 같이 논 것만으로도 멋지다.

## 🐣 마음 친구 키우기

알에서 태어난 아기를 **🍼 아기 → 🧸 꼬마 → 🖍️ 유치원생 → 🎒 초등학생 언니**가 될 때까지 키운다. 착하고 바른 멋진 언니로 크는 이야기다.

1. 알을 톡톡 세 번 두드리면 아기가 태어난다. 모양(🐰 토끼·🐻 곰·🐤 병아리)·색·이름은 아이가 고른다.
2. **돌보기**: 🍎 밥 · 🫧 씻기(친구를 문지른다) · 🎾 놀기(공 잡기) · 🌙 재우기(자장가) · 🤗 안아 주기(꾹 누르기). 돌보면 🌱 쑥쑥 자라는데, 하루에 자라는 만큼이 정해져 있어서 날마다 조금씩 돌보는 게 좋다. 할 일을 다 한 날엔 조금 더 큰다.
3. **🌟 바른 마음 알려 주기**: 친구가 겪은 일을 듣고 어떻게 하면 좋을지 골라 알려 준다. 그리고 “왜 그렇게 하면 좋을까?”까지 함께 생각한다. 아쉬운 쪽을 골라도 “그러면 친구가 속상할 것 같아. 이렇게 해 볼까?” 하고 다정하게 이끈다.
   - 🍼 아기: 🙇 인사하기 · 🙏 고마워
   - 🧸 꼬마: 💬 미안해 · 🤝 나눠 쓰기 · 🧺 정리하기
   - 🖍️ 유치원생: ⏳ 차례 지키기 · 🤗 도와주기 · 🌈 솔직하게 · 🤙 약속 지키기
   - 🎒 초등학생 언니(다 큰 뒤 멋진 언니 수업): 🌷 양보하기 · 👏 칭찬하기 · 🧡 동생 챙기기 · 🦁 용기 내기 · 💧 아껴 쓰기 · 💪 스스로 하기
   - 쑥쑥 게이지가 차고 그 단계의 바른 마음을 다 배우면 다음 단계로 자란다. 자랄 때마다 옷차림이 바뀐다(턱받이 → 리본 → 노란 유치원 모자 → 책가방과 1학년 이름표).
4. **💭 마음 알아맞히기**: 친구가 겪은 일을 듣고 기분을 고른 뒤, 위로하는 말을 고른다(감정 낱말 익히기).
5. **🎒 입학 카드**: 초등학생 언니가 되면 자란 날, 알려 준 바른 마음, 함께 돌본 날을 담은 카드를 준다. 그 뒤로는 더 자라지 않고 계속 같이 논다.

친구는 죽거나 아프지 않는다. 오래 안 오면 “보고 싶었어!” 하고 반겨 준다. 친구 그림은 이 앱에서 새로 그렸다.

## 🧸 숨바꼭질 (키즈카페 두더지 잡기)

놀이 이름은 가족 설정 데이터에 저장된 이름을 쓴다(없으면 “곰돌이 숨바꼭질”).
신나는 키즈카페 **아무 데서나** 곰돌이가 뿅! 튀어나왔다가 숨는다. 보일 때 재빨리 누르면 점수가 오른다(반짝 곰돌이는 +2).

- **🐰 토끼는 잡으면 안 된다!** 누르면 -1. 단계가 오를수록 토끼가 자주 나온다.
- 한 단계는 60초. 목표(1단계 15개, 단계마다 +5)를 채우면 **바로** 🏆 트로피를 받고 다음 단계로 간다.
- 단계가 오를수록 곰돌이가 빨리 숨고(1.65초 → 0.6초), 한 번에 나오는 친구도 늘어난다(2 → 5마리).
- 시간 안에 목표를 못 채우면 게임 끝 — “괜찮아요! 다시 해 볼까요?” 트로피와 최고 단계는 아이마다 저장된다.

## 📘 영어책 AR

- 부모님 화면 → 아이에서 아이의 AR 점수를 넣는다(예: 2.5).
- 책을 넣거나 고칠 때 그 책의 AR을 적는다. 책 뒤표지나 AR BookFinder에서 찾을 수 있다.
- 책마다 😊 술술 책(아이 점수보다 0.5 넘게 낮음) · 👍 딱 맞는 책(+0.7까지) · 📈 도전 책(그보다 높음)으로 표시한다.
- 책장 위 카드에 읽은 책 평균 AR과 종류별 권수를 보여 준다. 셋 다 칭찬한다.

시작 화면에 오늘 날짜·요일·날씨와 ✨ 긍정 한마디 슬라이드(“나는 할 수 있어!” 같은 말이 몇 초마다 넘어가고, 🔊로 들을 수 있다)가 뜨고, 두 아이 카드에 이번 주 성과와
오늘 할 일 진행률이 함께 보인다.

## 놀이 승인이 동작하는 방식

1. 아이가 오늘 할 일을 모두 마치면 `🔔 부모님께 승인 받기`가 열린다.
2. 누르면 `requests` 문서가 생기고, **같은 계정으로 앱을 열어둔 모든 기기**
   (부모님 휴대폰 포함)에 `○○이가 놀이를 하고 싶대요!` 카드가 몇 초 안에 뜬다.
3. 부모님이 `승인`을 누르고 PIN을 입력하면 아이 패드가 즉시 열리고 타이머가 돈다.
4. 시간이 끝나면 자동으로 다시 잠긴다.

> **카카오톡 알림이나 휴대폰 푸시는 이 페이지에서 보낼 수 없다.** 브라우저 페이지가
> 외부로 메시지를 보내려면 서버가 필요하다. 지금은 부모님이 앱을 열었을 때 알림 카드를
> 보는 방식이다. 카카오톡까지 원하면 Supabase Edge Function을 하나 세워야 한다.
>
> 승인 로직은 `requestUnlock()` / `approveRequest()` 두 함수로 분리돼 있어
> 나중에 카카오를 붙일 때 그 자리만 바꾸면 된다.

## 책 등록이 동작하는 방식

`책 등록` → 카메라로 뒤표지 바코드 → ISBN을 읽는다. 제목은 이 순서로 채운다.

1. **카카오 책 검색** — 부모님 설정에 REST 키가 있으면
   `GET https://dapi.kakao.com/v3/search/book?target=isbn&query=<ISBN>`,
   헤더 `Authorization: KakaoAK <키>`. 제목으로 찾기(`target=title`)도 지원한다.
2. **Claude에게 묻기** — 카카오가 없거나 실패하면 ISBN으로 책을 추정한다(아이가 고칠 수 있다).
3. **직접 적기** — 그래도 없으면 손으로 적는다.

어느 경우든 **표지를 사진으로 찍어** 책장에 남길 수 있고, 바코드가 안 읽히는 책도
`바코드 없이 직접 적을래요`로 등록된다.

등록할 때 **📗 다 읽었어요 / 📘 읽을 예정이에요**를 고른다.

- **📗 다 읽었어요** → 별점 → 어려웠던 낱말(단어 가방에 담긴다) → 💭 한 줄 느낌. 읽은 책장에 쌓인다.
- **📘 읽을 예정이에요** → 읽을 책장에 꽂힌다. 낱말·느낌은 묻지 않는다.
- 읽을 책장에 있던 책의 바코드를 다시 찍거나, 책을 누르고 **📗 다 읽었어요!**를 누르면 읽은 책장으로 옮겨 가며 별점·낱말·느낌을 묻는다.
- 이번 주 읽은 책 수·책왕에는 다 읽은 책만 센다.

### 카카오 REST 키 받는 법
1. https://developers.kakao.com 로그인 → 내 애플리케이션 → 애플리케이션 추가하기
2. 앱 키 화면의 **REST API 키**를 복사
3. 앱에서 부모님 화면 → 설정 → `카카오 책 검색 REST 키`에 붙여넣기

키는 코드에 박혀 있지 않고 설정에만 저장된다. 하루 호출 한도는 넉넉하다.

> **알라딘·네이버 API는 쓸 수 없다.** 두 곳 다 `Access-Control-Allow-Origin` 헤더를
> 보내지 않아 브라우저에서 원천적으로 호출이 막힌다(알라딘은 JSONP도 CORB에 걸린다).
> 프록시 서버를 세우면 가능하지만 이 앱에는 서버가 없다. 카카오는 `Authorization`
> 헤더까지 허용하는 CORS를 정식 지원해서 고른 것이다.

> **카카오 표지 이미지(`thumbnail`)는 표시되지 않을 수 있다.** Artifact CSP가 외부
> 이미지도 막기 때문이다. 그래서 표지는 직접 찍은 사진을 기본으로 삼는다.

## 데이터와 백업

기록은 `db`에, 사진은 `assets`에 저장된다. 로그인하지 않고 열면 노란 경고 배너가
뜨고 기록이 저장되지 않는다.

- **백업**: 부모님 화면 → 설정 → `전체 기록 내보내기`
- **📂 기록 관리**: 부모님 화면 → 기록 관리에서 아이를 고르고, 할 일 · 한 일 기록 · 책장 · 단어 가방 · 생각 기록 · 여행 · 가고 싶은 곳 · 여권 도장 · 받은 칭찬 · 이번 주 약속 · 받아쓰기 · 철자 기록을 보고 ✏️ 고치거나 🗑 지운다. 지우기 전에 줄 안에서 한 번 더 묻는다. 함께 간 여행은 그 아이 기록에서만 빠진다. 모은 별 개수는 부모님 화면 → 아이에서 고친다.
- **샘플 데이터**: 설정에서 넣고 뺄 수 있다. 예시로 넣은 항목은 `sample:true`로
  표시돼 있어 아이가 직접 넣은 기록은 건드리지 않고 한 번에 지운다.

## 코드 구조

단일 파일 안에서 역할별로 나뉘어 있다.

| 구역 | 내용 |
|---|---|
| `Store` | `db`가 있으면 db, 없으면 메모리. 모든 쓰기가 여기를 지난다 |
| `connect()` | `claude.use()`로 기능을 붙이고 컬렉션마다 `onSnapshot` 구독 |
| `view*()` | 화면별 HTML 문자열. 상태를 바꾸고 `render()`를 부르면 다시 그린다 |
| `kakaoSearch()` | 카카오 책 검색. 실패 사유(`nokey`/`badkey`/`blocked`…)를 구분해 돌려준다 |
| `lookupWord()` | Claude에게 JSON 스키마를 고정해 묻고 `dict` 컬렉션에 캐시 |
| `seedSample()` / `clearSample()` | 예시 데이터 |

PIN은 아이의 충동을 막는 잠금이지 보안 장치가 아니다(개발자 도구로 우회 가능).
